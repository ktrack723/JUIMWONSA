# 🎖 무사고 100일: 주임원사

> 만년상사. 이번이 마지막 진급 기회다. **무사고 100일**을 찍으면 원사 진급.
> 사고가 터지면 카운터는 0으로 돌아간다. 병사들은 그대로 남아서, 당신을 지켜본다.

연애조작단 2077(이 저장소의 전신)과 같은 문법으로 만들었다 — **한 장의 구조도가 곧
게임**이고, 구조도에 없는 것은 게임에 없다. 서버 없음, 빌드 없음, GitHub Pages에서
그대로 돈다. `js/llm.js`(업자 판별·캐시·재시도·구조화 출력)는 전작에서 그대로 왔다.

## 노는 법

1. `python3 -m http.server 8000` (또는 GitHub Pages) → `index.html`
2. API 키를 붙여넣는다. 업자 선택란은 없다 — 키 접두사가 곧 업자다
   (Anthropic `sk-ant-` / OpenAI `sk-` / OpenRouter `sk-or-`).
3. 부대를 하나 골라 부임한다. **부임일은 현실의 오늘 − 100일로 소급 기재된다** —
   한 번도 안 터뜨린 완주는 정확히 현실의 오늘 진급 심사를 맞는다.
4. 하루가 한 턴이다. 아침 브리핑을 읽고, 일과 아홉 슬롯이 돌고, 사건이 터지면
   달려가 지침을 내린다(또는 무시한다). 일과 중 쓸 수 있는 것은 셋 —
   🗣 면담 · 🔦 불시점검 · 📢 공지. 전부 평판 −1.

## 이 게임의 셈법

- **가라**를 높게 유지하면 행복하지만, 힘든 일을 대충 하면 다친다 (난이도·지능과의 곱).
- **갈등·부조리**를 적당히 두면 잔사고가 줄지만, 8을 넘기면 탈영·자해가 열린다.
- 정보를 보려면 **평판**을 내야 하는데, 평판이 낮으면 지침이 안 먹힌다.
- 파라미터 계기판은 없다. 브리핑은 수치가 아니라 **증상**을 말한다 — 읽는 눈이 실력이다.
- **사건**은 아직 사고가 아니다. 대응에 실패해 확전된 사건만이 **사고**고,
  그때만 카운터가 0이 된다. 날짜는 절대 돌아가지 않는다.

## 구조 — 프롬프트 하이어아키

색이 곧 데이터의 출처다: 🟩 static(부대 프롬프트·계절·사건 풀) · 🟦 user(공지·질문·지침) ·
🟫 cached(병사 프로필) · 🟧 once(브리핑·장면·소견) · ⬛ code(파라미터·롤·판정 결과).

블록은 일곱이다 (`js/prompts.js` — 여기 없는 프롬프트는 없다):

| 블록 | 하는 일 | 못 보는 것 |
|---|---|---|
| U | 부대 프롬프트 5절 — 모든 생성 호출의 system 접두사 | ④⑤의 수치 (코드 몫) |
| P | 전입 병사 생성 (등급은 코드가 굴린다) | 현재 파라미터 · 명부 |
| D | 아침 브리핑 + 슬롯별 일상 조각 | 파라미터 수치 (밴드까지만) |
| E-1/E-2 | 사건 장면 / 대응 결과 (D와 같은 하루 스레드) | — |
| E-3 | 확전 판정 → `contained \| escalated` + 방향 셋 | **지침 원문 · 파라미터 · 부대 프롬프트** |
| I-1 | 면담 — 병사의 대사 | 부대 전체 파라미터 (자기 체감만) |
| I-2 | 불시점검 소견 | 그 장소가 안 드러내는 파라미터 |
| N | 공지 판정 (방향) + 익명 반응 한 줄 | 파라미터 현재값 |

평판은 **어떤 LLM 판정도 못 움직인다** — 개입 횟수가 곧 평판이다.
이 표가 곧 회귀 테스트다 (`tests/hierarchy.test.mjs`).

## 파일

| 파일 | 하는 일 | 출처 |
|---|---|---|
| `js/llm.js` | API 클라이언트 (업자 판별·캐시·재시도·구조화 출력) | 전작 그대로 |
| `js/prompts.js` | 카트리지 — 일곱 블록의 프롬프트와 스키마 전부 | 신규 |
| `js/params.js` | 수치 전부 — 눈금·드리프트·사고 롤·등급 추첨·장소 대응표. LLM 없이 단독 테스트 | 신규 |
| `js/units.js` | 부대 프롬프트 2종 + 스키마 검증 (셋째 군은 항목 하나 추가로 끝) | 신규 |
| `js/roster.js` | 병사 저장·군번 채번·전입/전역 수명주기 (`localStorage`) | 신규 |
| `js/engine.js` | 하네스 — 하루를 슬롯 단위로 돌린다. **DOM을 모른다** | 신규 |
| `js/game.js` | 화면·입력 | 신규 |
| `js/pacing.js` `js/audio.js` `js/ui.js` `js/boot.js` | 재생 속도 · 효과음 · DOM 손잡이 · 부팅 | 전작 재사용 |

## 테스트

```
npm test        # LLM 없이 전부 돈다 — 키도 크레딧도 필요 없다
npm run live    # 실제 API로 확전율 분포 검사 (지침 갈래 vs 무대응 갈래)
```

- `params.test.mjs` — 드리프트·사고 롤·등급 추첨·카운터. 갈등 8부터만 큰 사고가 열리는가,
  사고 후 카운터는 0인데 파라미터·명부는 그대로인가.
- `hierarchy.test.mjs` — 표식 주입 전수 검사(§6의 차단 표) · 수치 누출 · 한글 누출.
- `engine.test.mjs` — 결정적 가짜 LLM으로 하루 3턴: 조용한 날 1콜 → 사건·확전(리셋) →
  다음날 브리핑에 어제가 요약되는가.
- `units/roster/schema/llm/pacing` — 각 층의 계약 테스트.
